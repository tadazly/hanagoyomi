# 地点搜索与手动选择

内置 50,000 个城市/城镇，按 GeoNames 快照筛选，覆盖 245 个国家和地区、3,833 个一级行政区分组。分组中的“其他行政区”表示原始数据未指定一级行政区，不是新增行政区划。

网页的“更换地点”支持中英日名称和别名搜索，结果逐行显示城市、国家/地区和行政区。可组合输入，例如 `Springfield Illinois`，以区分重名地点。最多显示 20 条结果，缩小查询后可找到其余地点。

“使用我的位置”下方新增“手动选择”，按国家/地区 → 行政区 → 城市/城镇选择，点选城市即生效。各级使用单行名称、细分隔线和选中勾号，支持返回和连续滚动，列表不分页；国家和行政区通过顶部已选路径区分，不重复显示第二行。右侧 A–Z 字母拉条支持点按、鼠标拖动、触屏滑动及键盘上下/Home/End 定位；中文界面的国家/地区按中文名称的拼音排序与分组，例如中国归 Z、美国归 M、日本归 R、秘鲁归 B。其余列表按英文或罗马字名称分组，未使用的字母不可点。国家末组定位到列表底部，拉到 Z 时“中国”整行可见；长城市组仍从组首进入。关闭浮窗不会修改地点。Wallpaper Engine、Plash 和壁纸预览隐藏搜索框与设备定位按钮，通过手动列表完成选择；WE 的内容拖动和字母拉条显式更新滚动位置，不依赖宿主转发滚轮。WE 原生城市下拉保留原有 90 个快捷城市。

选择后保存地点 ID、三语名称、国家和行政区、经纬度及地点时区；切换界面语言或重载不会混淆重名城市。旧版地点记录继续有效。“跟随当地”仍使用所选地点坐标请求天气和空气质量。WE 原生模式的启动优先级不变；需要启动时保留世界设置中的完整地点，请使用默认的“使用世界设置”模式。

设备定位使用 Open-Meteo 的 `timezone=auto` 按经纬度解析当地时区，不采用系统时区或附近快捷城市的时区。时区查询失败时保留原地点并提示重试或手选；后续手选、快捷城市或外部地点变更会取消旧定位及其时区请求，迟到结果不会覆盖新选择。有稳定 ID 时只按 ID 标记选中；旧版快捷地点在打开列表后按原名称和坐标解析国家、行政区，勾号不依赖目录是否预先加载。

网页首次搜索或打开手动选择时才下载压缩地点库；独立 WE 构建内嵌数据，离线也可选地点。设备定位的时区解析、天气和空气质量需要联网。中国大陆、台湾、香港、澳门、新加坡共有 2,900 个内置地点，2,899 个有中文名；按用户决定，唯一无法确认的深圳 `Wushipai` 保留原名。61 个可识别行政区均有中文名；无行政区代码仍显示“其他行政区”。日本 47 个行政区、1,485 个地点均有日文显示名，其中 4 个为明确标记的片假名转写，原名汉字和标准读音待核实；另有「みやこ」「上五島」的原名或坐标疑点。其余地区沿用已有译名，缺译时回退英文。旧 ICU 不认识 `America/Coyhaique` 时按其 2025 年起全年 UTC-3 的规则回退为固定偏移，历史时刻不能用该回退精确还原。

GeoNames 部分记录混用旧地名、聚居点与行政区，个别坐标、类型和地区归属也存在疑点；名称补全不代表重新认证了全部坐标。已发现的问题记录在补充名称表的 `note` / `unresolved` 中。

## 更新数据

从 [GeoNames 下载目录](https://download.geonames.org/export/dump/) 下载 `cities1000.zip`、`alternateNamesV2.zip`、`admin1CodesASCII.txt`、`countryInfo.txt`，保存在仓库外的同一目录，运行：

```powershell
python -X utf8 scripts/prepare-locations.py <原始数据目录>
```

生成 `src/assets/locations.bin` 和 `src/data/location-catalog.json`。筛选保留原有 90 个地点、各国家/地区与一级行政区的最大聚居点及首都，再按人口补足 50,000 条；坐标和时区使用源数据，旧地点保留原设置。别名采用 en/zh/ja 及其变体，并补采中国等汉字地区未标语言的汉字别名；最后应用 `src/data/location-names-cn.json`、`location-names-zh-regions.json`、`location-names-ja.json` 中按 ID 校对的本地名称和明确的错误别名排除项。补译可能保留尚重、夏庄等源库对应的历史地名，相关限制逐条标注。

这三份 JSON 是重建时使用的补译源表，`source`、`note`、坐标比对距离和待核事项供追溯使用，不进入运行时地点库，也不由网页或 WE 导入。发布产物只包含压缩后的名称、别名、坐标、时区和国家/行政区引用；不会打包这些校对记录。脚本与单测检查各地本地名称覆盖以及元数据未泄漏。清单记录输入、输出与补译表 SHA-256、数据结构、名称覆盖率和大小；补译表以 UTF-8、LF 换行计算文本哈希，二进制及原始下载文件按字节计算；同一组输入可重复生成相同输出。许可与署名见 [第三方声明](../THIRD_PARTY_NOTICES.md)。
