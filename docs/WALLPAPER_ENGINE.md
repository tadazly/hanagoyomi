# 壁纸模式与 Wallpaper Engine

## 浏览器预览与 Plash

在网站链接上增加 `?wallpaper=1`，例如 [壁纸模式](https://hanagoyomi.luyilabs.com/?wallpaper=1)，即可使用与独立壁纸包相同的布局、默认行为、30 FPS 预览上限及独立的 `wallpaper.*` 本地偏好。普通网站入口保留原有行为。此模式不会伪造 Wallpaper Engine 原生属性，也不会在重载时用原生默认值覆盖浏览器设置。

Mac 的 Plash 可直接添加此链接。页面也会识别 Plash 注入的 `html.is-plash-app` 类；显式参数可确保首次载入就进入壁纸模式。在 Plash 中修改世界设置前，先启用 **Browsing Mode**，调整后关闭该模式即可继续作为桌面背景展示。Plash 的交互方式与类名见 [官方文档](https://sindresorhus.com/plash)。浏览器/Plash 与 Wallpaper Engine 使用相同逻辑，但不同浏览器和宿主之间不会同步本地存储。

## 导入场景分享链接

在真实 Wallpaper Engine 中，打开主窗口的“已安装”，选中花暦。默认“使用世界设置”会隐藏其余原生选项，包括链接输入；需粘贴时先取消勾选，再将完整链接粘贴到“导入场景链接”（`sceneimportlink`）。如需保留导入后的完整风景，可在画廊应用前重新勾选“使用世界设置”，待导入链接会保留。返回桌面点击“预览风景”，再选择加入收藏、应用或还原。有效链接先作为待导入场景，粘贴、重新加载或启动时恢复链接均不会自动预览、替换世界或加入收藏；无效链接也不会改变世界。清空原生输入框可清除待导入链接。

普通浏览器与 Plash 可直接打开完整分享 URL；预览壁纸布局时同时保留 `?wallpaper=1`。这些环境没有 WE 原生输入属性，本机世界、城市、语言和画质偏好仍各自独立，打开分享链接不代表覆盖已保存的世界。

网页中不重复提供粘贴导入框。壁纸模式的作品菜单提供二维码分享，不依赖宿主剪贴板或外跳；普通浏览器另提供复制链接与手动复制回退。壁纸模式隐藏依赖网页键盘的收藏改名入口，浏览器可点击收藏标题改名。独立 `file://` 包分享默认指向 `https://hanagoyomi.luyilabs.com/`，可在构建时通过 `VITE_SCENE_SHARE_URL` 指定其他已部署支持此协议的 HTTPS 网站。

原生输入采用 [官方 `textinput` 用户属性](https://docs.wallpaperengine.io/en/web/customization/properties.html)，不依赖 Workshop Web 页面中的键盘或粘贴输入框。官方未公布文本长度上限，发布前应在真实 WE 原生窗口验证完整链接粘贴与重载恢复。网页侧只接收 `wallpaperscenelink` 事件的 `detail.link` 字符串，再负责校验及明确确认；该属性不进入世界设置宿主快照，也不触发设置保存或取消已有预览。通知排在当前同步初始化后的 microtask，避免遗漏启动时缓存的链接。

## 构建与导入

```powershell
npm ci
npm test
npm run build:wallpaper
```

将 `dist-wallpaper/index.html` 导入 Wallpaper Engine 编辑器；只导入这个独立目录。壁纸包含经典脚本、样式、城市和星表，不需要 Node.js、本地服务器或 CDN。`npm run build` 仍生成原网站到 `dist/`，不会包含壁纸默认行为。

`wallpaper/project.js` 定义分类及原生属性，默认标题与描述采用英文，避免编辑器更新覆盖 Steam 的默认英文版本。`wallpaper/workshop-copy.js` 保存已审核的中文、日文、英文工坊文案，三语标题均包含 `Flower Meadow`。`wallpaper/preview.gif` 为创意工坊动态预览，随独立构建一起打包。

`dist-wallpaper/workshop-title.txt` 和 `workshop-description.txt` 为默认英文文案；带有 `.english`、`.schinese`、`.japanese` 后缀的对应文件和 `workshop-localizations.json` 提供三套独立文案。在 Steam 工坊的“编辑标题与描述”中按语言分别保存，不能只在同一份描述中拼接三语。中文描述额外包含 B 站演示：https://www.bilibili.com/video/BV1mopT6oExv/；三语均保留 YouTube 演示：https://www.youtube.com/watch?v=oxYg9Qka6ak。

## 默认体验与设置

- WE 原生面板默认勾选“使用世界设置”（`useworldsettings`）。勾选时始终使用内置世界设置，其余原生参数隐藏且不应用，旧属性快照也不能覆盖本地世界。世界设置和画廊应用的风景自动保存在本机，重启恢复；新开关缺失或延迟到达也先按勾选处理，保护升级前的世界。渲染比例恢复为 100%，其余画质与界面偏好使用本机保存值。
- 取消勾选后，立即完整应用 WE 保存的选项，每次启动也完整应用，覆盖世界设置中的对应项。世界设置与画廊仍可编辑当前世界，但修改只能单向生效，无法回写 WE 右侧数值；对应项会在下次启动重新被 WE 覆盖。WE 没有对应选项的细节继续保留。单向限制见 [WE 开发者说明](https://steamcommunity.com/app/431960/discussions/1/3108018050527080579/)。
- 从 WE 模式重新勾选时保留此刻的世界，停止后续原生覆盖，不另行切换一套历史配置。勾选本身不提交或取消画廊预览；取消勾选或真正改变原生参数时先还原临时预览再应用。原生明确调整时间或天气会解除对应场景锁，其他锁保留。两种模式均遵循 WE 的全局 FPS 与暂停控制。
- 高画质，保留体积云、4× MSAA、景深、Bloom 和镜头雨滴。不自动降低用户选定的画质。
- 关闭手动场景交互，开启自动飞行；两项独立运行。
- LOGO 默认右上，时间天气默认中下；两者都可选择九宫格位置或隐藏。
- 底部组件、工具栏和沉浸模式返回按钮保留任务栏安全留白。
- 初次启动收起世界设置。工具栏位于右下角，鼠标移入后显示，移出 4 秒隐藏；设置面板、时间面板或帮助打开时保持显示。
- 取消勾选时提供城市、天气模式、时刻、画质、渲染比例、交互、飞行、组件位置、温度单位、语言与常用效果。天气预设仅在手动模式显示，模拟时刻仅在不跟随现在时显示，组件位置与温度单位按组件显示状态展开。移除“打开完整世界设置”原生开关，旧 `settingspanel` 回调也不再消费；桌面右下角始终可打开世界设置。原生运行中只应用真正变化的属性，避免无关回调重置当前世界；每次启动与切入 WE 模式均绕过快照去重完整应用。此顺序遵循 [官方属性事件契约](https://docs.wallpaperengine.io/en/web/api/propertylistener.html)。
- “低饱和度配色”默认关闭，也可在完整面板的“画面”中切换。开启后使用鼠尾草绿与橄榄绿草地、柔和花色和较轻的夜间发光，仍随时间和天气变化；背景虚化与画面暗角均独立设置。
- 原生城市下拉包含所有内置城市，无需在桌面输入搜索文字或使用浏览器定位。自动地点按系统时区选择代表城市，并非精确定位。
- 世界设置按“常用 / 天气 / 画面 / 界面”组织。常用保留地点、时间、自动飞行、手动操纵及高度预设；细节参数默认折叠。画面暗角默认开启，可独立关闭并跨重载保存；背景虚化设为 0% 时远近景物都保持清晰。
- 网站与壁纸使用独立的本地偏好，互不覆盖。
- “界面 → 启动与恢复”中的“记住上次位置”默认开启；关闭后，下次启动从默认低空位置和视角开始，天气、时间与其他设置仍保留。此开关仅影响启动，收藏预览和分享风景仍使用作品自己的构图。世界设置标题旁的问号可打开使用帮助，天气数据保持展开。
- WE 模式也提供“记住上次位置”。启动时按原生值校正相机恢复策略，即使它与上次桌面保存值相反；运行中切换此选项不会立即跳转相机。世界模式只遵循桌面保存值。
- 天气过渡中重启后，未锁定的手动天气与“关闭天气效果”继续向已保存的目标过渡；锁定风景按快照恢复，不重启天气过渡。
- 壁纸中品牌不再跳转关于页面，天气数据来源与许可保留普通文字署名；不提供网页跳转。全屏按钮、键盘与滚轮帮助改为适合桌面的鼠标操作说明。
- 壁纸内语言使用可编辑按钮组，避开 CEF 离屏渲染显示原生下拉框时的崩溃；普通网站继续使用下拉框。两种 WE 模式、浏览器与 Plash 均可在桌面切换语言。
- 世界设置和使用帮助均支持直接拖动内容并在松手后惯性减速，同时提供自绘滚动条、轨道点击与上下翻阅按钮，兼容宿主中原生滚动条无法操作的情况。滚动不受手动场景交互开关影响。桌面 Web 壁纸不应依赖滚轮：[官方开发者说明](https://steamcommunity.com/app/431960/discussions/2/3969311271670416631/)指出宿主限制输入为鼠标移动和点击，页面无法通过 JavaScript 恢复未传入的滚轮事件。浏览器预览保留滚轮支持，普通网站继续使用原生滚动；预览通过不代表桌面滚轮可用。
- 桌面常用城市按钮在两种模式均可选择，WE 模式还提供原生城市下拉；宿主不转发键盘时优先使用按钮或原生下拉。画廊、世界设置和时间面板互斥；切到设置时保留候选风景及还原点。打开画廊时工具栏保持可见。时间天气组件始终显示观测位置的实况，三个场景锁单独保存。

## 性能与恢复

早期注册 `wallpaperPropertyListener`，在应用就绪前缓存属性。帧率遵循 `applyGeneralProperties.fps`；没有宿主时预览默认 30 FPS。分辨率默认按屏幕渲染，主场景最多约 829 万像素，超出时等比降低；原生渲染比例允许进一步降低至 50%。云缓冲仍保留原有像素上限。

暂停时停止动画调度。恢复时重置帧计时、云历史与性能采样，真实时钟重新跟随系统时间，过期天气刷新；模拟时间不会因暂停而突然快进。WebGL context 恢复后重载并重建资源，同一页面会话限制两分钟内重复自动重载。

画面可离线运行。真实天气与空气质量依赖 Open-Meteo；壁纸保留最近三小时内的天气缓存并明确标记，缓存不可用时回退动态天气，来源按实际状态显示。第三方署名与许可随构建提供。壁纸本身没有音频。

## 验收要求

测试和构建不能替代宿主验收。发布前在真实 Wallpaper Engine 中验证：默认勾选与旧版升级、勾选后原生选项隐藏且不生效、取消勾选后的条件显隐、两种模式切换及全量应用、桌面控件可编辑、两种模式的重载优先级、双方位置记忆值相反时的启动相机、画质与帧率、暂停恢复、分享链接粘贴与清空重贴、有效链接仅待导入、无效链接不影响世界、重载不自动导入、画廊预览/还原/应用及重载、4 秒工具栏、设置与帮助的内容拖动/惯性/滚动条/上下按钮、组件位置保存、昼夜与雨雪、断网回退，以及超宽屏布局。另验收浏览器 `?wallpaper=1` 与 Plash Browsing Mode，不能将预览通过当作真实宿主或桌面滚轮可用。提交后核对 Workshop 页面、动态预览、三语简介、演示视频与公开状态。

若出现黑屏、页面停止或进程退出，应分别记录 WebGL context 丢失、JavaScript 异常及原生进程崩溃。通过 Wallpaper Engine 的 CEF DevTools 端口读取实际运行页面的 console、显卡与资源状态，参见 [官方调试流程](https://docs.wallpaperengine.io/en/web/debug/debug.html)。浏览器中的恢复模拟不能证明真实宿主崩溃已修复。

后续更新同一条 Workshop 作品时，更新原编辑器项目的构建资源，保留其 `project.json` 中的 `workshopid`，并从原项目提交更新。独立构建不携带作品 ID，便于首次导入，不能直接覆盖原项目的发布身份。

更新原编辑器项目时，其默认标题与描述也应保持英文；中日文通过工坊网站的语言字段维护。更新后逐页核对 `english`、`schinese`、`japanese` 文案，并检查未提供翻译的语言是否回退英文。分类 Genre 在官方编辑器中为单选，本项目保留 Nature。

发布或更新后，Steam 可能暂时将作品标记为“不兼容”。[官方说明](https://help.wallpaperengine.io/en/interface/exclude.html)将其归为反垃圾检查，通常数小时内自动解除；无需重复上传或修改壁纸来绕过检查。
